Chaves da Revolut X

Esta página cria o par de chaves para a MyFinance ler a tua cripto na Revolut X (só leitura). As chaves são criadas aqui, neste browser: não são enviadas para lado nenhum nem ficam guardadas. Se fechares a página antes de as copiares, gera outras.

1 · Chave pública → Revolut X

Em exchange.revolut.com → Perfil → Chaves de API → criar chave: cola esta chave pública e escolhe a permissão só de leitura. A Revolut X mostra-te depois a chave de API (64 caracteres).

2 · Chave privada → GitHub (nunca a envies a ninguém)

No repositório myfinance-sync → Settings → Secrets and variables → Actions → New repository secret:

  • nome REVX_PRIVATE_KEY → cola esta chave privada inteira (com as linhas BEGIN e END);
  • nome REVX_API_KEY → cola a chave de API de 64 caracteres que a Revolut X te deu.
